How Product Photo Test Lab tests AI product photo tools

By Ted · Published 2026-10-28 · Last updated 2026-10-28

Who runs this: Ted. Ted works at Uneedcomms, the company that makes ModoAI (Modo AI). ModoAI is one of the tools covered in this lab, and every tool, ModoAI included, is scored with the same rules. How tests are run.

How does Product Photo Test Lab test AI product photo tools?

Every tool gets the same product photo and prompt text, pasted word for word into a new chat. Only the first image is scored, plus up to two edits from a fixed list. Each final image is scored 1 to 5 on five criteria, for a total out of 25, and every run records date, account, model and time.

Which input photo is used?

An unlabeled amber glass dropper bottle with a black ribbed cap, photographed by Kadarius Seegars and published on Unsplash under the Unsplash License. It was chosen because it has no brand marks, which makes invented text easy to spot, and because glass, reflections and the small pipette show distortion quickly. Every tool receives the same 1600 × 2400 px JPEG.

Input photo: Kadarius Seegars / Unsplash.

What are the test conditions?

Prompts10 fixed prompts, identical on every tool page, pasted word for word
SessionsA new chat for each prompt. In ChatGPT a regular chat, because image creation was not available in temporary chats
Which image is scoredThe first image returned. No rerolls to pick a better one
EditsUp to two, from three fixed messages: E1 restore the product, E2 remove invented marks, E3 one targeted change (wording recorded)
TimingSeconds from pressing send, read from page timestamps: to the first image in Gemini, to the finished image in ChatGPT. Untimed runs are marked
PlanRound 1 used ChatGPT Free and a Google Workspace business account (Pro tier shown) for Gemini. The Gemini free tier is planned for the next round. The account used is named next to every result
Location and languageSouth Korea, English prompts, web browser on a desktop computer
Images shownImages as saved from each app's result view, resized for the web, no retouching or cropping. Full-size downloads are noted when checked

How is each image scored?

Five criteria, each scored 1 to 5, for a total out of 25. A 2 or 4 means the image sits between the anchors.

CriterionWhat is checked135
Product fidelityShape, proportions, cap, bulb and pipette match the inputDifferent product, or a key part missing or reshapedClearly the same bottle, one detail changed (for example cap ribs or pipette missing)Indistinguishable from the input bottle
Text and marksNo unrequested text, label or logo. For prompt 8: requested text spelled exactly and wrapped on the glassInvented branding, or prompt 8 text misspelledSmall stray mark, or prompt 8 text correct but flat or warpedClean glass, or prompt 8 label correct and natural

RealismLight, shadow, reflections, glass transparency, contact with the surfaceObviously artificial: floating product, wrong shadowsBelievable at a glance, flaws visible on a closer lookReads as a real photograph at full size
Store-readyCould go on a product page or ad without retouchingUnusableUsable after light retouchingUsable as delivered

How are tools treated fairly?

  • Same input file, same prompt text and the same edit messages for every tool that accepts a written prompt.
  • Where another tool beats ModoAI, the page says so. Two known cases: ModoAI does not generate people or hands, and it does not put text on products.
  • Facts about a tool's features, plans or prices come only from that tool's official pages, with the date they were checked.
  • ModoAI starts from a photo rather than a prompt, so its run follows its own normal flow (upload, recommended style, proposed concepts) and is scored on the same five criteria.
  • The lab is run by Ted, who works at Uneedcomms, the company that makes ModoAI. That interest is stated on every page.

How often are tests re-run?

Each tool page is re-run every four weeks, and within two weeks when a tool ships a new image model. Old results stay in the update log with their dates, so changes over time remain visible.

How can I check or repeat a result?

Download the input photo from Unsplash, copy a prompt from the Nano Banana 2 or ChatGPT page, and run it in a new chat. Expect some variation, since image models return a different image each time. If you find an error, open an issue on GitHub.

What are the limits of this method?

  • One product, one input photo. Results on fabric, food or matte packaging can differ.
  • One scored run per prompt per tool. Image models are random, so a second run can score higher or lower. Where a re-run was done, it is listed in the update log.
  • One person scores every image (Ted), using the written rubric on the methodology page. Scores are a documented judgment, not a lab measurement.
  • Accounts differed in the first round: Nano Banana 2 ran on a Google Workspace business account (Pro tier shown) and ChatGPT on the Free plan.
  • Tests are run from South Korea, in English. Limits and models can differ by country and account.
  • Tools change often. Every result carries its run date and the model name the app showed on that day.
