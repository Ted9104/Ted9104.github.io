카페24 적립금 주는법: 구매·회원가입·리뷰·직접 지급 4가지 (2026)

작성 킵그로우 팀 · 2026-11-03

카페24에서 적립금을 주는 방법은 네 가지입니다. ① 적립금 설정에서 구매 금액의 일정 비율을 지급하고, ② 같은 화면에서 회원가입 적립금을 정하고, ③ 게시판 관리의 '적립금 바로 주기 설정'으로 리뷰 적립금을 주고, ④ 특정 회원은 회원 상세 정보 창에서, 여러 회원은 적립금 일괄조정으로 직접 지급합니다.

1. 구매하면 적립금 주기

  1. [관리자] 쇼핑몰 설정 > 고객 설정 > 회원 정책 설정 > 적립금 설정으로 이동합니다.
  2. '상품 구매 시 적립금 지급 비율 설정'에 지급 비율을 넣습니다. 0%로 두면 구매 적립금이 지급되지 않습니다.
  3. '적립금 지급 시점 설정'에서 배송완료 후 익일·3일 후·7일 후·14일 후·20일 후 중 지급 시점을 고릅니다.
  4. 가장 늦은 선택지는 배송완료 20일 후입니다(카페24 도움말, 2026-11-03 확인).

2. 회원가입하면 적립금 주기

  1. 같은 적립금 설정 화면의 '지급 설정 > 회원가입 적립금 설정'으로 갑니다.
  2. 회원가입 때 지급할 금액을 입력하고 저장합니다.

3. 리뷰를 쓰면 적립금 주기

  1. [관리자] 게시판 > 게시판 관리에서 상품 후기 게시판의 제목을 눌러 게시판 정보 팝업 창을 엽니다.
  2. '적립금 바로 주기 설정'에서 '적립금 주기 버튼 표시(회원 상세 팝업 창 이용)' 또는 '설정 금액 표시 후 바로 지급'을 고르고 '수정'을 누릅니다.
  3. 관리자 확인 후 게시하는 방식이라면 '원클릭으로 적립금 지급 및 관리자 게시하기'를 체크해 지급과 게시를 한 번에 할 수 있습니다.
  4. 리뷰를 쓸 때 자동으로 주려면 카페24 레시피 기능의 '리뷰 작성 시 적립금 자동 지급' 레시피를 추가합니다. 도움말 기준으로 레시피는 일반 후기와 포토 후기를 나눠 지급 금액을 다르게 하기 어렵습니다.

4. 특정 회원이나 여러 회원에게 직접 주기

  • 한 명에게: [관리자] 고객 > 회원 조회 > 회원 정보 조회에서 회원 아이디를 눌러 회원 상세 정보 창을 엽니다. '적립금/예치금/쿠폰 > 적립내역 추가'에서 증감여부와 금액을 넣고 [추가]를 누릅니다. 차감도 같은 곳에서 합니다.
  • 여러 명에게 같은 금액: 회원 정보 조회에서 회원 목록을 엑셀로 내려받은 뒤, [관리자] 고객 > 회원혜택관리 > 회원 적립금 관리의 '적립금 일괄조정'에서 양식을 받아 채워 올리고 증액/차감 여부와 금액을 넣어 업로드합니다.

자주 묻는 질문

지급된 적립금은 언제부터 쓸 수 있나요?

구매 적립금은 적립금 설정에서 고른 시점(배송완료 후 익일·3일 후·7일 후·14일 후·20일 후)에 지급되고, 지급된 뒤 바로 쓸 수 있습니다. 쓸 수 있는 조건은 적립금 설정의 '사용/제한 설정'에서 정합니다. 예를 들어 '적립금 사용 가능 최소 상품 구매 합계액'을 50,000원, '최소 누적 적립 금액'을 5,000원으로 두면 한 번에 5만 원 이상 주문하고 적립금이 5천 원 이상 있어야 쓸 수 있습니다.

회원 등급별로 적립금을 다르게 주고 싶어요.

[관리자] 쇼핑몰 설정 > 고객 설정 > 회원 정책 설정 > 회원 등급 관리에서 등급명을 누르고 '구매 시 할인/적립 혜택'을 '적립금 지급'으로 정하면 등급별 추가 지급률을 넣을 수 있습니다. 특정 등급에 기본 적립금을 주지 않으려면 적립금 설정의 '적립금 지급제외 회원등급 설정'을 씁니다.

특정 상품에는 적립금을 못 쓰게 할 수 있나요?

적립금 설정의 '적립금 사용 예외 설정'에서 '지정된 분류에 포함된 상품 적립금 사용 제한' 또는 '지정된 상품 적립금 사용 제한'을 고르고 대상을 지정합니다.

적립금을 잘못 줬어요. 회수할 수 있나요?

[관리자] 고객 > 회원 조회 > 회원 정보 조회에서 회원 아이디를 눌러 회원 상세 정보 창을 열고, '적립금/예치금/쿠폰 > 적립내역 추가'에서 증감여부를 '적립금 차감'으로 고른 뒤 차감 금액을 넣고 [추가]를 누릅니다. 여러 명이면 적립금 일괄조정에서 차감으로 올립니다.
