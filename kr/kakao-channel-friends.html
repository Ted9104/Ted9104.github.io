회원가입할 때 카카오 채널 친구도 자동으로 추가되게 할 수 있어요?

네, 됩니다. 카카오싱크에서 대표 채널을 지정하면 가입 동의 화면에 [카카오톡 채널 추가] 항목이 선택 동의로 뜹니다(카카오 사전 준비 문서·데브톡 답변). 손님이 여기에 동의하면 가입과 함께 채널 친구가 됩니다. 직접 설정하는 순서는 다음과 같습니다.

  1. 카카오톡 채널 파트너센터에서 비즈니스 채널 심사를 받습니다.
  2. 카카오 디벨로퍼스에서 앱을 비즈 앱으로 전환하고 채널과 연결합니다. 연결 심사에서 앱과 채널의 사업자 정보가 같은지 확인합니다.
  3. 카카오 디벨로퍼스 > 카카오 로그인 > 동의항목 > 대표 채널을 지정합니다. 대표 채널이 없으면 동의 화면에 채널 추가 항목이 표시되지 않습니다.
  4. 테스트 계정으로 내 몰에 카카오 가입을 해 보고, 동의 화면에 채널 추가가 보이는지 확인합니다.

이 설정을 맡기고 싶다면 1초 회원가입 같은 앱이 있습니다. 1초 회원가입 공식 FAQ는 "카카오 1초 회원가입 시 마케팅 약관에 동의하면 별도 절차 없이 채널이 자동 추가"되고, 기존 회원에게는 채널 친구 유도 팝업을 띄운다고 안내합니다. 또 같은 FAQ는 고객이 사이트에서 탈퇴해도 채널을 직접 차단하지 않으면 채널 친구로 남는다고 안내합니다. 직접 연동과 앱의 차이는 카페24 카카오싱크 연동 방법 3가지에, 비용은 카카오싱크 비용에 정리했습니다.

  2. 이미 가입한 회원을 따로 모읍니다. 가입 동의 화면은 새로 가입하는 손님에게만 뜹니다. 광고 수신에 동의한 회원에게 채널 URL을 문자로 보내고, 주문 완료 화면과 마이페이지에 채널 추가 버튼을 둡니다.
  3. 택배 상자에 QR을 넣습니다. 물건을 받아 본 손님은 몰을 이미 아는 사람입니다. QR 옆에 "채널 추가하면 다음 주문 쿠폰"처럼 받을 혜택을 한 줄로 적습니다.
  4. 그래도 모자라면 광고를 씁니다. 카카오모먼트 전환 캠페인에서 광고 목표 대상을 카카오톡 채널로 고르면 기존 친구를 뺀 사람에게 광고가 나갑니다. 비용이 드는 경로라 마지막에 둡니다.

카페24 카카오 로그인 때 왜 채널 추가는 안 되나요?

먼저 카카오 디벨로퍼스에서 대표 채널이 지정됐는지 봅니다. 카카오 사전 준비 문서는 대표 채널을 고르지 않으면 동의 화면에 [카카오톡 채널 추가] 항목이 표시되지 않는다고 적고 있습니다. 카페24 호스팅 앱에서 채널 추가 약관이 안 뜬다는 문의에도 카카오는 대표 채널 설정을 안내했습니다(카카오 데브톡). 확인 순서는 이렇습니다.

  1. 카카오 디벨로퍼스 > 카카오 로그인 > 동의항목 > 대표 채널이 지정돼 있는지 봅니다.
  2. 연결한 채널이 비즈니스 채널 심사를 통과했는지 봅니다.
  3. 테스트 계정으로 다시 카카오 가입을 해 보고 동의 화면에 채널 추가가 뜨는지 확인합니다.

1초 회원가입을 쓰는 몰은 카페24 관리자의 SNS 로그인 연동에서 카카오싱크 설정을 직접 고치지 말라고 공식 FAQ가 안내합니다. 이 경우 킵그로우 채팅 상담으로 확인합니다.

카톡채널 친구추가 늘려주는 업체 써도 되나요?

이 글에서는 권하지 않습니다. 업체가 채워 준 친구가 내 몰 손님인지 확인할 방법이 없고, 채널 친구는 메시지를 받고 주문해야 의미가 있기 때문입니다. 돈을 쓴다면 대상과 비용이 카카오 관리자 화면에 남는 카카오모먼트 광고(표 ⑥)가 낫습니다.

단골들 카톡 채널로 모으고 싶은데 방법 있을까요?

"채널 추가해 주세요"라고 말로 부탁하면 손님은 카톡을 열고, 채널을 검색하고, 추가를 눌러야 합니다. 누르기만 하면 되는 링크나 찍기만 하면 되는 QR을 손님 손에 쥐여 줍니다.

  • 문자 한 통에 URL: 누르면 바로 채널 홈으로 갑니다. 광고 수신 동의자에게만 보내고 (광고) 표시와 수신 거부 방법을 넣습니다.
  • QR: 택배 동봉 카드, 매장 계산대, 팝업 행사 테이블에 둡니다. 채널 관리자센터 > 채널 홍보에서 받습니다.
  • 1:1 채팅 인증 혜택: 카카오 비즈니스 가이드는 채널 추가 뒤 1:1 채팅으로 인증받고 친구 추가 혜택을 안내하는 방식을 소개합니다. 쿠폰이나 사은품을 이 인증과 묶으면 됩니다.

채널 친구 추가 쿠폰은 누가 받았는지 어떻게 구분해요?

카카오 비즈니스 가이드는 채널 추가 뒤 1:1 채팅으로 인증받는 방식을 소개합니다. 이 방식으로 쿠폰 코드를 채팅으로 보내면 채팅 내역이 지급 기록이 되고, 사용 여부는 카페24 쿠폰 사용 내역에서 확인합니다(운영 팁). 회원가입과 함께 채널 친구가 되는 손님은 회원가입 쿠폰을 그대로 주면 따로 구분할 필요가 없습니다. 쿠폰 설정은 카페24 첫 구매 쿠폰·회원가입 쿠폰 설정에 있습니다.
