카페24 네이버 로그인 설정 방법: 네이버 로그인 플러스와 개발자센터 직접 등록 (2026)

이 글은 카페24 도움말과 네이버 개발자센터 문서를 기준으로 정리했습니다.

작성일 2026-11-19 · 마지막 확인 2026-11-19

카페24 쇼핑몰에 네이버 로그인을 붙이려면 네이버 로그인 플러스(카페24 관리자에서 신청, 네이버 추가 검수 없음)나 네이버 개발자센터 직접 등록(Client ID·Secret 발급 후 검수 승인) 가운데 하나를 고릅니다. 직접 등록할 때는 서비스 URL과 Callback URL에 쇼핑몰이 쓰는 도메인을 빠짐없이 넣고, 카페24 SNS 로그인 연동 관리에 키를 넣은 뒤 로그인 화면에 SNS 로그인 디자인을 적용해야 버튼이 보입니다.

카페24 네이버 로그인 설정 방법은?

카페24에서 네이버 로그인을 붙이는 방법은 두 가지입니다. 처음이라면 SNS 로그인 연동 관리의 '네이버 로그인 플러스 신청하기'로 앱을 만들면 네이버 추가 검수 없이 바로 쓸 수 있습니다. 직접 관리하려면 네이버 개발자센터에서 애플리케이션을 등록해 Client ID와 Client Secret을 받아 카페24에 넣고, 네이버 로그인 검수 승인을 받습니다(카페24 도움말).

구분네이버 로그인 플러스네이버 개발자센터 직접 등록
시작하는 곳카페24 SNS 로그인 연동 관리, 또는 판매 채널 > 네이버 > 네이버 로그인네이버 개발자센터 Application > 애플리케이션 등록
네이버 검수추가 검수 없음. 앱을 만들면 바로 사용'개발 중'으로 시작, 검수 승인 뒤 사용
가입 창네이버 회원 정보가 쇼핑몰 가입 항목을 모두 채우면 카페24 SNS 간편 가입 창을 생략도움말에 같은 안내 없음
함께 되는 것네이버 톡톡 계정 등록(가입 회원에게 톡톡 메시지)-

카페24 도움말 '네이버 로그인 플러스가 무엇인가요?'와 '네이버 클라이언트(앱) 아이디를 발급받으려면 어떻게 해야 하나요?' 기준입니다(2026-11-19 확인).

네이버 로그인 플러스로 설정하는 순서는 어떻게 되나요?

카페24 관리자 SNS 로그인 연동 관리(또는 판매 채널 > 네이버 > 네이버 로그인)에서 '네이버 로그인 플러스 신청하기'를 누르면 앱이 쇼핑몰에 자동으로 설치됩니다. 이어서 쇼핑몰의 네이버 계정으로 로그인하고, 애플리케이션 이름과 로고를 넣고, 네이버 톡톡 계정을 등록한 뒤 적용합니다. 카페24가 앱 정보를 보증하므로 네이버가 따로 검수하지 않는다고 도움말에 적혀 있습니다.

  1. SNS 로그인 연동 관리(또는 판매 채널 > 네이버 > 네이버 로그인)에서 '네이버 로그인 플러스 신청하기'를 누릅니다.
  2. 네이버 로그인 앱을 관리할 쇼핑몰의 네이버 계정으로 로그인합니다.
  3. 팝업의 이용 정보를 읽고 '동의'를 누릅니다.
  4. 애플리케이션 이름과 로고를 등록합니다.
  5. 이 앱으로 가입한 회원에게 마케팅 메시지를 보낼 네이버 톡톡 계정을 등록합니다.
  6. 애플리케이션과 톡톡 정보를 확인하고 적용합니다.

톡톡 메시지는 알림 받기에 동의한 회원에게만 보낼 수 있고, 네이버 톡톡 파트너센터에서 한 달에 한 번 무료 마케팅 메시지를 보낼 수 있다고 카페24 도움말에 적혀 있습니다.

네이버 개발자센터에서 직접 등록하려면 무엇을 입력하나요?

네이버 개발자센터의 Application > 애플리케이션 등록에서 애플리케이션 이름, 사용 API(네이버 로그인)와 받을 정보, 로그인 오픈 API 서비스 환경(PC웹·Mobile웹), 서비스 URL과 Callback URL을 넣습니다. 등록이 끝나면 내 애플리케이션의 개요 탭에서 Client ID와 Client Secret을 확인합니다. 회원이름과 이메일은 기본으로 넘어오는 정보이고, 추가로 고른 항목은 고객이 제공을 거부할 수 있습니다(카페24 도움말).

  1. 네이버 개발자센터에서 Application > 애플리케이션 등록으로 이동해 네이버 아이디로 로그인합니다.
  2. 약관동의 탭에서 API 이용약관에 동의하고, 계정 정보 등록 탭에서 계정을 설정합니다.
  3. 애플리케이션 이름을 넣습니다. 로그인하는 고객에게 보이는 이름이라 쇼핑몰 이름을 씁니다.
  4. 사용 API에서 '네이버 로그인'을 고르고, 회원가입 때 받을 정보를 고릅니다.
  5. 로그인 오픈 API 서비스 환경에서 PC웹과 Mobile웹을 하나씩 추가합니다. PC와 모바일 쇼핑몰에서 모두 쓰려면 둘 다 필요합니다.
  6. 서비스 URL과 네이버 로그인 Callback URL을 넣고 '등록하기'를 누릅니다(아래 표).
  7. Application > 내 애플리케이션에서 앱 이름을 누르고 개요 탭의 Client ID와 Client Secret을 복사합니다.

서비스 URL과 Callback URL에는 무엇을 넣나요?

서비스 URL에는 네이버 로그인을 쓸 쇼핑몰 도메인을, Callback URL에는 고객이 로그인한 뒤 돌아올 도메인을 사용하는 경우마다 모두 넣습니다. 보안연결(SSL)을 적용했다면 http와 https 주소를 Callback URL에 각각 넣고, 대표·서브·모바일·멀티샵 같은 2차 도메인도 모두 넣습니다. 서비스 URL에 없는 도메인에서 로그인하면 오류가 날 수 있습니다(카페24 도움말).

도메인이 sample.com일 때보안연결(SSL)서비스 URLCallback URL
PC 쇼핑몰적용 안 함http://sample.comhttp://sample.com, http://www.sample.com
PC 쇼핑몰적용함https://sample.comhttp://sample.com, https://sample.com, http://www.sample.com, https://www.sample.com
모바일 쇼핑몰적용 안 함http://sample.comhttp://m.sample.com, https://m.sample.com
모바일 쇼핑몰적용함https://m.sample.comhttp://m.sample.com, https://m.sample.com

카페24 도움말 '네이버 클라이언트(앱) 아이디를 발급받으려면 어떻게 해야 하나요?'의 입력 예시를 옮겼습니다. 서비스 URL을 더 넣을 수 있는지는 네이버 개발자센터에 문의하라고 도움말이 안내합니다.

카페24 관리자에는 어디에 넣고, 버튼은 어떻게 보이게 하나요?

[관리자] 쇼핑몰 설정 > 고객 설정 > 회원 가입·로그인 > SNS 로그인 연동 관리에서 네이버를 '사용함'으로 고르면 Client(App) ID와 Secret(Key) 입력 칸이 나옵니다. 값을 넣고 저장한 뒤, 로그인 화면 디자인에 SNS 로그인 버튼을 적용해야 쇼핑몰에 네이버 버튼이 보입니다. PC와 모바일 디자인에 각각 적용합니다.

  1. SNS 로그인 연동 관리에서 네이버를 '사용함'으로 고르고 Client(App) ID와 Secret(Key)를 넣어 저장합니다.
  2. [관리자] 디자인 > 디자인 보관함에서 대표 디자인의 '편집'을 누르고, 자주 쓰는 화면 > 로그인 > 회원 로그인 영역 '편집' > 꾸미기 탭에서 SNS 로그인 디자인을 적용합니다.
  3. 디자인 보관함의 모바일 탭에서 모바일 대표 디자인에도 같은 작업을 합니다.

SNS 로그인을 쓰면 SNS에서 받는 개인정보 항목을 쇼핑몰 개인정보 처리방침에 적어야 합니다. SNS 계정으로 가입했다가 탈퇴한 고객은 같은 SNS 계정으로 다시 가입할 수 없습니다(카페24 도움말). 버튼이 안 보이는 경우는 카페24 카카오 로그인 안 될 때의 디자인 적용 부분과 같습니다.

네이버 로그인 검수는 어떻게 요청하나요?

직접 등록한 앱은 '개발 중' 상태로 시작하고, 네이버 로그인 검수가 승인돼야 고객이 네이버 로그인을 쓸 수 있습니다. 검수를 요청하려면 쇼핑몰 로그인·회원가입 화면에 네이버 버튼 디자인이 적용돼 있어야 합니다. 테스터 아이디로 로그인 과정을 캡처해 첨부하고, 검수상태 탭에서 서비스 적용 형태를 '기타'로 고른 뒤 '카페24'라고 적습니다(카페24 도움말).

  1. 로그인·회원가입 화면에 네이버 로그인 버튼 디자인이 적용돼 있는지 확인합니다.
  2. 멤버관리 탭에서 네이버 로그인이 되는 테스터 아이디를 등록합니다.
  3. 테스터 아이디로 내 쇼핑몰에서 네이버 로그인을 해 보며 과정을 캡처해 파일 하나로 저장합니다. 네이버 로그인 버튼과 약관 동의 화면이 꼭 들어가야 합니다.
  4. API 설정 탭에서 로그인 오픈 API 서비스 환경의 로고 이미지를 등록하고 '수정'을 누릅니다.
  5. 네이버 로그인 검수상태 탭에서 제공 정보 활용처(사용 API에서 고른 항목)를 체크하고, 서비스 적용 형태는 '기타'에 '카페24'로 적은 뒤 캡처 파일을 첨부해 등록합니다.
  6. 상태가 '검수 요청'으로 바뀌면 승인을 기다립니다.

카페24는 네이버 아이디로 로그인할 때 비밀번호를 받는 단계가 따로 없습니다. 이 때문에 검수가 거부되면 네이버에 정확한 검수 확인을 요청하라고 카페24 도움말이 안내합니다.

네이버 로그인 도입 비용은 얼마인가요?

네이버 로그인 API는 무료이고, 위 순서대로 직접 설정하면 추가 비용이 없습니다. 카카오와 네이버를 함께 붙이고 설치를 맡기려면 간편가입 앱을 쓰는데, 1초 회원가입은 두 버튼을 함께 제공하고 이미 쓰고 있다면 네이버 로그인에 추가 비용이 없습니다(공식 FAQ). 1초 회원가입 요금은 Basic 월 49,900원, Standard 월 69,900원(부가세 제외)입니다.

카카오 쪽 연동과 비용은 카페24 카카오싱크 연동 방법과 카카오싱크 비용에, 설치를 맡길 수 있는 앱은 카페24 간편가입 앱 비교에 정리했습니다.

자주 묻는 질문

네이버 로그인 플러스로 만들면 검수가 없나요?

카페24 도움말에 따르면 네이버 로그인 플러스로 만든 앱은 카페24가 앱 정보를 보증하므로 네이버가 추가로 검수하지 않고, 앱을 만들면 쇼핑몰에서 바로 네이버 로그인을 쓸 수 있습니다.

직접 등록했는데 테스트 아이디만 로그인되고 고객은 안 돼요.

앱이 아직 '개발 중' 상태일 가능성이 큽니다. 네이버 개발자센터 내 애플리케이션의 네이버 로그인 검수상태 탭에서 검수 요청과 승인 여부를 확인합니다.

PC는 되는데 모바일에서만 네이버 로그인이 안 돼요.

로그인 오픈 API 서비스 환경에 Mobile웹을 추가했는지, m. 도메인을 Callback URL에 넣었는지 확인합니다. 버튼이 아예 없다면 디자인 보관함의 모바일 대표 디자인에 SNS 로그인 디자인을 적용합니다.

네이버 로그인 앱을 새로 만들어 다시 연결해도 되나요?

권하지 않습니다. 카페24 도움말은 발급받은 Client(App) ID를 바꾸면 기존 회원 정보, 주문 정보와 연동할 수 없다고 안내합니다. 예전에 쓰던 앱이 있다면 그 앱을 그대로 연결합니다.
