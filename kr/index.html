카페24 네이버·카카오톡 로그인 연동 요약: 두 연동의 순서 비교와 오류 점검

카페24에서 네이버·카카오톡 로그인을 켜는 길은 두 갈래입니다. 카카오는 쇼핑몰 명의의 카카오톡 채널과 카카오 디벨로퍼스 앱을 먼저 마련한 다음 관리자의 SNS 로그인 연동 메뉴에서 카카오싱크 간편설정을 진행하고, 네이버는 네이버 개발자센터가 발급한 Client ID·Client Secret 두 값을 같은 메뉴에 입력합니다. 어느 쪽이든 설정값 저장이 끝이 아니라, 가입 이력이 없는 계정으로 PC·모바일 양쪽에서 가입해 보는 것까지가 한 묶음입니다.

메뉴 위치는 카페24 도움말 기준 쇼핑몰 설정 > 고객 설정 > SNS 로그인 연동 관리이며, 관리자 화면이 개편되면 경로가 달라질 수 있습니다.

순서카카오톡 로그인(카카오싱크)네이버 로그인
1쇼핑몰 명의 카카오톡 채널과 디벨로퍼스 앱 마련. 예전에 만든 앱이 있으면 계속 쓸지부터 결정개발자센터에 애플리케이션을 새로 등록하고 사용 기능에서 네이버 로그인 선택
2카페24 연동 메뉴의 카카오 항목에서 간편설정과 일반 카카오 로그인 중 하나를 고름제공받을 정보를 필수와 추가로 나눔. 쇼핑몰 가입 양식의 필수 칸과 맞춤
3간편설정 화면에 쇼핑몰·사업자 정보를 넣고 신청. 카카오 쪽 심사가 있어 하루 안에 끝나지 않을 수 있음서비스 URL과 Callback URL 입력. PC 주소, 모바일 주소, 자체 도메인을 빠짐없이
4이메일·이름·휴대전화번호처럼 가입에 쓸 동의 항목만 고름발급된 Client ID와 Client Secret 확인. Secret은 남에게 공유하지 않음
5카페24에서 사용함으로 바꿔 저장카페24 네이버 항목을 사용함으로 바꾸고 두 값을 붙여 넣음. 앞뒤 공백이 섞이지 않게
6가입 이력 없는 카카오 계정으로 PC·휴대폰 가입 시험기존 회원 연결 방식을 정해 저장하고, 애플리케이션이 개발 중 상태라면 공개 전 전환이나 검수가 필요한지 확인

연동을 붙이는 방식은 운영자가 쓸 수 있는 시간과 가입 화면을 얼마나 바꾸고 싶은지에 따라 고릅니다.

  • 관리자에서 직접: 기본 로그인 버튼이면 충분하고 위 표를 따라갈 여유가 있을 때.
  • 개발 외주: 가입 화면을 크게 손보거나 다른 회원 시스템과 묶어야 할 때. 문제가 생기면 누가 고치는지, 키 값과 계정은 누가 보관하는지 계약 전에 못 박아 둡니다.
  • 앱스토어 간편가입 앱: 설치와 가입 화면 정리를 함께 맡기고 싶을 때. 예컨대 1초 회원가입은 카페24·아임웹 쇼핑몰용 앱으로 카카오 간편가입과 가입 시 카카오톡 채널 추가 동의를 제공하며, 카페24 쇼핑몰이라면 네이버 간편가입도 같이 쓸 수 있습니다.
