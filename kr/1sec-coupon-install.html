1초 쿠폰 설치 방법: 카페24 앱 설치부터 적용 완료까지 4단계 (신청 후 최대 5일)

이 글은 1초 회원가입과 1초 쿠폰을 만든 유니드컴즈(킵그로우) 직원이 썼습니다.

작성 킵그로우 팀 · 작성일 2026-11-06 · 마지막 확인 2026-11-06

1초 쿠폰은 유니드컴즈(킵그로우)가 만든 카페24 쇼핑몰용 쿠폰 앱입니다. 설치는 ① 카페24에서 앱 설치 ② 운영자 계정 정보를 입력해 신청 ③ 킵그로우가 쇼핑몰 스킨에 직접 적용 ④ 완료 알림, 신청 후 최대 5일 안에 끝납니다. 설치 프로그램을 내려받는 방식이 아니고, 토스 페이스페이의 '쿠폰 1초 자동 적용'과는 다른 서비스입니다.

1초 쿠폰은 무엇인가요?

상품 가격 바로 아래에 '이 쿠폰을 쓰면 얼마'인 예상 최저가를 표시하고, 쿠폰 열림·마감 알림과 시간한정 쿠폰 자동 발급을 제공하는 카페24 앱입니다. 출시일은 2026-11-02(보도자료 기준)입니다. 카페24 쇼핑몰에서만 쓸 수 있습니다.

1초 쿠폰 설치 방법 4단계

  1. 카페24에서 앱을 설치합니다. 카페24 스토어에서 1초 쿠폰을 설치합니다. 앱 설치는 대표운영자 계정으로 진행합니다.
  2. 운영자 계정 정보를 입력해 신청합니다. 공식 페이지에는 계정 정보가 암호화되어 저장된다고 안내돼 있습니다.
  3. 킵그로우가 쇼핑몰 스킨에 직접 적용합니다. 운영자가 코드를 만지지 않습니다. 스킨을 바꾸면 다시 맞춰 줍니다.
  4. 완료 알림을 받습니다. 신청 후 최대 5일 안에 적용됩니다.

적용 뒤 운영자가 직접 바꿀 수 있는 항목은 알림 위치와 색, 쿠폰함 블록 순서, 타임쿠폰 요일과 시간입니다. 스킨에 하단 구매 바가 이미 있는 몰은 구매 바 표시 토글이 비활성화되며 변경은 고객센터 문의가 필요합니다(공식 페이지).

요금과 해지

  • Basic 월 49,900원(월 방문자 30만 미만), Standard 월 69,900원(30만 이상), 부가세 별도. 후불이며 다음 달 1일에 이용일수만큼 일할 청구. 첫 달은 방문자 수와 관계없이 Basic.
  • 해지는 카페24에서 앱을 삭제하면 되고 쇼핑몰 화면은 원래대로 돌아갑니다.

토스 페이스페이 '쿠폰 1초 자동 적용'과는 다른가요?

다릅니다. 토스 페이스페이는 오프라인 매장에서 얼굴 인식 결제 시 토스 앱 쿠폰이 자동 적용되는 소비자용 기능입니다. 1초 쿠폰은 온라인 카페24 쇼핑몰 운영자가 설치해 상품 가격 아래에 쿠폰 적용 예상 최저가를 보여주는 앱입니다. 이름에 '1초'가 들어가지만 회사도 용도도 다릅니다.

자주 묻는 질문

1초 쿠폰은 어떻게 설치하나요?

카페24 스토어에서 앱을 설치하고, 운영자 계정 정보를 입력해 신청하면 킵그로우가 쇼핑몰 스킨에 직접 적용합니다. 신청 후 최대 5일 안에 완료 알림을 받습니다. 운영자가 코드를 수정하지 않습니다.

1초 쿠폰 설치에 비용이 드나요?

설치 지원은 요금에 포함됩니다. 요금은 Basic 월 49,900원(월 방문자 30만 미만), Standard 월 69,900원(30만 이상), 부가세 별도 후불이며 첫 달은 Basic이 적용됩니다.

1초 쿠폰은 토스 페이스페이 쿠폰 자동 적용과 같은 건가요?

아닙니다. 토스 페이스페이는 오프라인 얼굴 인식 결제의 소비자용 쿠폰 기능이고, 1초 쿠폰은 유니드컴즈(킵그로우)가 만든 카페24 온라인 쇼핑몰용 쿠폰 앱입니다.

설치 후 스킨을 바꾸면 어떻게 되나요?

킵그로우가 다시 맞춰 줍니다. 설치 및 재패치 지원이 요금제에 포함돼 있습니다.

1초 쿠폰을 해지하면 쇼핑몰은 어떻게 되나요?

카페24에서 앱을 삭제하면 해지되고 쇼핑몰 화면은 원래대로 돌아갑니다.
